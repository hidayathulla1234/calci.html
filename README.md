# 🧮 Calculator Web App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations and works on both desktop and mobile devices.

---

## 🚀 Features

- ✔ Basic arithmetic: addition, subtraction, multiplication, and division  
- ✔ Decimal support  
- ✔ Clear and backspace functionality  
- ✔ Responsive UI  
- ✔ Works on all modern browsers

## 💻 How to Run the Project

1. Download or copy the project files.
2. Save them in a folder.
3. Open `index.html` in your browser (Chrome, Firefox, Edge, etc.).
4. Use mouse clicks or keyboard input to perform calculations.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| HTML      | Structure of the calculator |
| CSS       | Styling and layout |
| JavaScript | Logic and button functionality |

---

## 🧠 How It Works

- HTML provides the calculator layout (buttons, display screen)
- CSS styles and formats the calculator appearance
- JavaScript listens to button clicks and evaluates expressions to generate results
